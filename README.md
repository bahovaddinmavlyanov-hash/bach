# s21_matrix

Собственная реализация библиотеки для работы с числовыми матрицами на языке С — проект в рамках учебной программы Школы 21.

## Описание

Библиотека `s21_matrix.a` реализует базовые операции линейной алгебры над матрицами: создание и удаление, сравнение, сложение, вычитание, умножение (на число и на матрицу), транспонирование, вычисление определителя, матрицы алгебраических дополнений и обратной матрицы.

Матрица представлена структурой:

```c
typedef struct matrix_struct {
  double** matrix;
  int rows;
  int columns;
} matrix_t;
```

Все функции (кроме сравнения) возвращают код результата:

| Код | Значение |
|---|---|
| `0` (`OK`) | успешно |
| `1` (`ERROR`) | некорректная матрица |
| `2` (`CALCULATION_FAILURE`) | ошибка вычисления (несовпадающие размеры, вырожденная матрица и т. д.) |

## Реализованные функции

| Функция | Назначение |
|---|---|
| `s21_create_matrix` | создание матрицы |
| `s21_remove_matrix` | очистка и освобождение памяти |
| `s21_eq_matrix` | сравнение двух матриц (точность — 6 знаков после запятой) |
| `s21_sum_matrix` | сложение матриц |
| `s21_sub_matrix` | вычитание матриц |
| `s21_mult_number` | умножение матрицы на число |
| `s21_mult_matrix` | умножение матрицы на матрицу |
| `s21_transpose` | транспонирование |
| `s21_determinant` | вычисление определителя (рекурсивно, разложением по первой строке) |
| `s21_calc_complements` | матрица алгебраических дополнений |
| `s21_inverse_matrix` | обратная матрица |

## Технологии

- Язык: **C11** (`gcc` / `clang`)
- Стиль кода: Google C++ Style Guide
- Юнит-тесты: библиотека **Check**
- Покрытие тестами: **gcov / gcovr** (отчёт в HTML)
- Статический анализ памяти: `-fsanitize=address`

## Сборка и запуск

```bash
make all           # сборка статической библиотеки s21_matrix.a
make test          # сборка и запуск юнит-тестов
make gcov_report    # запуск тестов + HTML-отчёт покрытия (logs/report.html)
make clean          # очистка артефактов сборки
make rebuild        # clean + all
```

После `make gcov_report` отчёт автоматически открывается в браузере (`logs/report.html`).

## Тестирование

Юнит-тесты покрывают все функции библиотеки и проверяют:
- корректную обработку граничных и некорректных входных данных (`NULL`, нулевые/отрицательные размеры);
- совпадение размеров матриц перед арифметическими операциями;
- точность вычислений (сравнение до 6 знаков после запятой);
- корректность определителя и обратной матрицы для матриц разного порядка.

Запуск: `make test`. Покрытие каждой функции — не менее 80%.
